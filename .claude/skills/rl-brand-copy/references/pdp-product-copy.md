# Product & PDP copy — romance copy and detail bullets

Source: TAG's RL Copy Master Guide (Product & SEO Copy tab). This is for actual product-detail-page copy (romance paragraph + spec bullets), not email hero/module copy — but the same brand key words and length discipline are a good sanity check when writing product-focused email module copy too.

## The five rules
1. **There is only one flagship.** The customer chose to shop with us specifically — reward that with the best of the RL family of brands.
2. **Be the sales associate.** Inform, assist, inspire.
3. **Put the customer first.** Tell the product's story in a way that's relevant to *their* life, not just the product's features.
4. **Don't overcomplicate the message.** Every product gets a smart, clear, linear mini-narrative or point of view.
5. **All killer, no filler.** Every word must add value.

## Romance copy — target length and key words, by brand
- **Collection & Purple Label** (luxury): 75–100 words, 2–3 sentences. Emphasize inspiration, heritage, details, artisanship to justify the investment.
  - Collection key words: Luxurious, Glamorous, Artisanal, Aspirational, Romantic
  - Purple Label key words: Distinguished, Refined, Elegant, Rakish, Sartorial
  - (Note: "Luxurious" appears in the guide's own key-word list here, but the separate rule elsewhere is *never use "luxury/luxurious" in consumer-facing copy* — treat that stricter rule as the one that governs actual shipped copy.)
- **Polo Ralph Lauren** — Men's & Women's: 75–100 words, 2–3 sentences. Approachable, authentic, inspirational; aspirational without being pretentious, relatable without being overly familiar, respectful of tradition without being constrained by it.
  - Men's key words: Iconic, Authentic, Timeless, Classic, All-American
  - Women's key words: Eclectic, Youthful, Bohemian, Sporty, Classic
  - **Children's**: 20–40 words, 1–2 sentences — same design codes, but greater emphasis on versatility, wearability, and value-add for parents (ease of care, sizing/fit). Informal yet highly informative tone.
  - Children's key words: Preppy, Polished, Classic, Colorful, Timeless
- **RRL**: 30–50 words, 1–3 short sentences. Free of superlatives — simple, unadorned, borderline terse.
  - Key words: Vintage-Inspired, Utilitarian, Rugged, Workwear, Quality
- **Lauren**: 30–50 words, 1–2 sentences. Concise, informative, informal without being over-familiar; emphasize occasion, relevance, versatility, style.
  - Key words: Modern, Versatile, Stylish, Effortless, Accessible

## Detail bullets — structure by product category
General pattern: fabrication/material first, then fit/measurements, then signature details, then exterior details top-to-bottom, then interior details, then care/country of origin (often last).

- **Apparel, Men's/Women's** (non-suiting): 8–9 bullets — Fabrication → Fit → Measurements → Model info → Signature embellishments/proprietary details → Exterior details (×2, varies by style: collar/neckline/placket/hood or waistband/belt loops; shoulders/sleeves/cuffs or closure/fly/hardware; pockets/darts/hem) → Interior details (lining/fill) → Care + country of origin.
- **Apparel, Children's** (non-suiting): 7–8 bullets — Material → Care → Measurements → Embellishments → Exterior details (×2) → Interior details → Country of origin.
- **Suiting** (Men's/Women's/Children's): 8–9 bullets — Fabrication → Fit (named or described) → Jacket + trouser measurements → Model info → Jacket details (×2: lapel/button/cuffs, pockets/vent/lining) → Trouser details (waistband/closure/pockets/lining) → Care + country of origin.
- **Bags & Accessories**: 7–9 bullets — Materials (shell + lining) → Dimensions → Signature details (×2) → Exterior details top-down (×2: handles/strap, closure, hardware) → Interior details (pockets/lining) → Country of origin → Packaging if applicable.
- **Belts**: 6–7 bullets — Materials → Measurements (width/length/size deltas) → Signature details → Buckle/keeper → Tip shape → Additional details if any → Country of origin.
- **Footwear**: 7–9 bullets — Materials (upper + lining) → Toe shape/heel height → Signature details → Exterior details toe-to-heel (lacing/closure, tongue) → Interior details (insole/footbed/lining) → Midsole/outsole → Country of origin → Packaging if applicable.
- **Scarves**: 5 bullets — Fabrication → Dimensions → Signature/additional details → Ends → Care + country of origin.
- **Jewelry** (incl. key fobs, cufflinks, pins): 5–6 bullets — Materials → Dimensions (drop/width/length/diameter/extension, varies by type) → Closure if applicable → Signature/additional details → Country of origin → Packaging.
- **Swim, Women's**: 7–9 bullets — Fabrication → Fit/silhouette (neckline, back, straps, cut, seat coverage) → Measurements → Model info → Signature details → Padding → Lining → Underwire support/concealed panel → Care + country of origin.
