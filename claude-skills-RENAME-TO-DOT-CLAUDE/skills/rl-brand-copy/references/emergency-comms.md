# Emergency / crisis comms — pattern only, not current wording

Source: TAG's RL Copy Master Guide (Emergency Corp Comms tab). The source document's actual content is a COVID-19-specific toolkit from 2020 — a tagline, "we believe" statements, and forbidden/approved word lists built for that specific crisis. That wording is dated and **should not be reused for a different situation** without fresh sign-off; it's not included here for that reason.

## What's durable: the shape of a crisis-comms toolkit
If a real crisis situation requires messaging, the pattern this brand has used before is:
1. **One main tagline** that can anchor every piece of messaging across channels.
2. **A short "we believe" statement** (1–2 numbered points) establishing the company's stance.
3. **A forbidden-words list and an approved-words list**, built fresh for the specific situation — emotionally loaded words that could read as insensitive get banned, steadier/hopeful words get approved. (The 2020 list banned words like "Storm," "Darkness," "Fear," "Difficulty" and approved words like "Hope," "Faith," "Rise," "Strength" — illustrative of the *kind* of split to make, not a list to reuse verbatim for an unrelated crisis.)
4. **Example commitments** — concrete, specific actions (a dollar figure, named initiatives) rather than vague solidarity statements.
5. **A short quote** from company leadership, signed off with warmth ("With love, Ralph Lauren" was the 2020 sign-off style).

## If this situation actually arises
Don't draft crisis copy from this skill alone — flag it to the user immediately as something that needs real-time sign-off from RL leadership/legal, not just brand-voice judgment. This is the one category of copy where "sounds on-brand" isn't a sufficient bar.
